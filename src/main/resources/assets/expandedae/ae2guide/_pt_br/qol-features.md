# O mod adiciona todos os recursos de qualidade de vida listados abaixo
## Multiplicação de Padrões nos Fornecedores de Padrões: Isso adiciona um botão ao Fornecedor de Padrões que permite multiplicar ou dividir todos os Padrões contidos.
__Os multiplicadores se acumulam!__

![modify_patterns.png](assets/modify_patterns.png)
## Modos Extras de Bloqueio: Isso adiciona dois modos extras de bloqueio a todos os Fornecedores de Padrões
### Padrão: Este é o modo de bloqueio padrão do AE2, ele enviará o padrão se o armazenamento conectado não contiver nenhum dos insumos do padrão neste Fornecedor de Padrões. Se o armazenamento contiver algo que não seja um insumo do padrão, o modo de bloqueio o ignorará e ainda assim enviará o padrão.
    
![blocking_1.png](assets/blocking/blocking_1.png)

### Completo: Este modo de bloqueio não enviará o padrão se o armazenamento conectado contiver qualquer coisa.
    
![blocking_2.png](assets/blocking/blocking_2.png)

### Inteligente: Permite que o Fornecedor de Padrões envie o mesmo padrão se o armazenamento de destino contiver apenas os insumos deste padrão específico.

![blocking_3.png](assets/blocking/blocking_3.png)
