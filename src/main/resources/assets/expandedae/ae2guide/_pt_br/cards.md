## Atualmente, o mod adiciona apenas os dois cartões de melhoria listados abaixo.
- Cartão de Conclusão Automática: Este cartão é uma melhoria para Fornecedores de Padrões, 
cancelando automaticamente a fabricação assim que o padrão for enviado. 
_Nota: Pode causar problemas com padrões de fabricação, então tenha cuidado_ 
<ItemImage id="auto_complete_card" />
- Cartão de Reabastecimento de Padrões: Este cartão é uma melhoria para o <ItemLink id="wireless_exp_encoding_terminal" /> 
e o <ItemLink id="ae2wtlib:wireless_universal_terminal" /> Este cartão é uma melhoria para o fornecedor que reabastece 
automaticamente o slot de padrão vazio no Terminal de Codificação Expandido.
_Nota: O cartão só tenta reabastecer os padrões cada vez que o botão de codificação é clicado; essa foi a solução mais eficiente em termos de recursos._
<ItemImage id="pattern_refiller_card" />
